<h1 align="center">🎮 Jogo de Adivinhação em Python</h1>

<p align="center">
Projeto desenvolvido para prática de lógica de programação em Python.
</p>

<hr>

<h2>📚 Sobre o projeto</h2>

<p>
Este projeto é um jogo simples onde o jogador deve adivinhar um número aleatório gerado pelo programa.
O jogador possui um número limitado de tentativas para acertar.
</p>

<h2>⚙️ Tecnologias utilizadas</h2>

<ul>
<li>Python</li>
<li>VS Code</li>
<li>Git e GitHub</li>
</ul>

<h2>🎮 Como jogar</h2>

<ol>
<li>Execute o arquivo <b>jogo.py</b></li>
<li>Digite um número entre 1 e 50</li>
<li>Tente acertar o número secreto</li>
</ol>
